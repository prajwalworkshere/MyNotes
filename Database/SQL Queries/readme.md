# 🗄️ SQL Queries — Learning & Practice

Welcome to my SQL learning repository! This section contains my SQL notes, queries, examples, and hands-on database practice, organized topic by topic.

My goal is to build a strong foundation in SQL, understand relational databases, solve real-world problems, and prepare for technical interviews.

## 🎯 Learning Objectives

- Understand SQL syntax and database fundamentals.
- Practice CRUD operations and data manipulation.
- Master filtering, sorting, grouping, and aggregate functions.
- Understand different types of joins and subqueries.
- Learn database relationships, keys, and constraints.
- Practice advanced SQL queries and optimization techniques.
- Work with practical databases and solve interview questions.

## 💡 My Practice Approach

For every topic, I aim to follow this process:

1. Understand the concept and syntax.
2. Write SQL queries from scratch.
3. Execute the queries against sample data.
4. Analyze the output and understand why it works.
5. Practice variations and edge cases.
6. Solve real-world and interview-style problems.
7. Save the queries and update the topic's GitHub link.
